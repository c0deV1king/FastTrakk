# FastTrakk
All-in-one data dashboard focused on the tracks, laptimes, and records.

## Features:
__1__ - 3D world map sphere with the option to choose which track you want to focus on. <br>
__2__ - Historical data of each track, as well as top records, zones and corners. <br>
__3__ - A dashboard layout with a live feed of drivers details on track. <br>

### 1
> Spinable earth with waypoints to each track on the map that can be interacted with with a few different "menu" options, including the navigation to the dashboard.

### 2
> Tracks in detail, showcasing a 3D track render of the track layout, pins of the corners and colourful showcasing of the zones. <b>
Lots of interactivity bringing up external videos and other cool facts based on the selected area.
_Example:_ Selecting a corner will bring up a HUD with the name of the corner, any cool facts and a video of racing on it if available.

### 3
> A dashboard to use as a "companion" during live races on a second display. More details will be noted here later on.
<br>

>[!IMPORTANT]
>Currently, only Formula 1 will be supported but there are plans for other motorsports if it is viable and works with the intended features.
